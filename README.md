# FolksandFocus Metabolic Intelligence

A professional, locally runnable product prototype for governed obesity and metabolic expert intelligence in India.

Run `npm start`, then open `http://127.0.0.1:4174`. Run `npm test` for the domain model tests.

The service models resolved HCP identities, immutable evidence claims, versioned and explainable scorecards, governed safety-case transitions, and audit events. The local repository is in memory so the prototype stays dependency-free. A production implementation should map these entities to PostgreSQL, store source snapshots in object storage, use a queue for ingestion, and project only verified relationships into a graph database.

Safety detections are potential cases only and must remain human-reviewed. All people, institutions, claims and cases in this build are synthetic scenario data, not clinical, regulatory or commercial facts.
