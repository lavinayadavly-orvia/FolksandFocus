## Experience Mapping

`generated/reported-experience.mjs` stores source observations, separate from the immutable cohort identity artifact. Imports require the same institutional profile URL and normalized doctor name; unmatched names and conflicting experience amounts remain in review. Directory data is not used to create extra doctors.

`reported-experience.mjs` is shared by profile presentation and listening coverage. Exact reported years use the agreed non-overlapping bands. A reported lower bound such as `30+ years` provisionally uses the reported minimum, retains the plus sign, and explains on the profile that actual experience could fall in a higher band. No registration year is manufactured. This experience-based classification does not establish influence, account ownership, clinical consensus or posting activity.

Collectors retain source URLs, timestamps, hashes and source locators. `scripts/collect-profile-experience.py` supports Aster biography sections and CARE labelled experience fields, matches the profile heading, respects robots/crawl delays and checkpoints, and holds conflicting amounts. `scripts/import-directory-experience.mjs` merges those observations without replacing other hospitals' evidence. `scripts/import-reported-experience.mjs` handles Medicover's public directory JSON. The blocked Max automated directory attempt is not retried; only its previously retrieved public page was imported.
